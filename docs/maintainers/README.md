# Maintainer Documentation

This directory contains documentation intended for Apollo maintainers only. These documents cover internal processes,
workflows, and procedures that are not relevant to end users or general contributors.

> [!NOTE]
> The processes below are inherited from upstream Sunshine. Apollo release automation and
> secrets must be configured for the Apollo repository before they are used.

## Available Documentation

### [Release Process](release.md)
Instructions for creating and managing Apollo releases, including the steps to convert pre-releases to stable releases
and an overview of the automated workflows that are triggered during the release process.
